# Technical synthesis

A robot motion program can be technically correct, but still fail. The prime example is the problems that may arise when it is around people. For example, a delivery robot could correctly follow its programmed path and end up in the correct location. However, its behavior could still be unsafe or confusing if there is many people. People do not know where the robot path is which can cause issues if the robot gets in their way. Technical tests of the robot’s code and motion would not be enough to determine whether it works well in this environment. Additional evidence should include testing with pedestrians walking around the robot's path. We can also observe how people react to the robot. This would evaluate both technical correctness and real-world use.
