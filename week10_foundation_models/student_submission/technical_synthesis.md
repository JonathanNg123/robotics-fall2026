The three missions in this lab really taught me a lot about how hard it is to make a functioning robot. In Mission 1, I learned that being specific with instructions helps the model understand what the robot is supposed to do. If you are not, the robot just will not respond like how you would wamt it to. My improved request told the robot to navigate to the shelf, inspect the cup, report its observations, and return to base. In Mission 2, I learned that the model can make assumptions about images. For example, when I asked which tool would help draw a circle, the model suggested a compass. Although this took did make sense for the task at hand, it was not specific in explaining whether the tool was actually visible in the photograph. This showed me why we need to compare the model's claims with visual evidence. In Mission 3, I learned that even detailed movement instructions do not guarantee successful navigation. My improved prompt included specific waypoints, but the robot still failed to reach the goal. One remaining limitation is that the model can struggle to follow directions consistently, even when the instructions are clear.
